# PAP - Plataforma de Venda e Troca de Materiais de Construção

## Descrição

Este projeto consiste no desenvolvimento de uma plataforma web destinada à
venda e troca de materiais de construção.

A plataforma permitirá aos utilizadores publicar anúncios de materiais,
consultar materiais disponíveis, pesquisar produtos e contactar outros
utilizadores interessados.

## Objetivos

- Permitir o registo e autenticação de utilizadores;
- Permitir a publicação de anúncios;
- Permitir a venda de materiais de construção;
- Permitir a troca de materiais;
- Permitir a pesquisa de materiais;
- Permitir filtrar materiais por diferentes categorias;
- Permitir o contacto entre utilizadores;
- Criar uma interface simples e intuitiva.

## Tecnologias
